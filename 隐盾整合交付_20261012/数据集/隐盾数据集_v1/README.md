# 隐盾数据集 v1：拿来即可开始开发

交付日期：2026-10-14。这里有实际数据文件、训练格式、可重复生成脚本、校验程序及两人独立复核材料。没有调用付费 API，没有收集真实个人档案。

先双击 `打开数据预览.cmd` 或直接打开 `预览数据.html`，即可看到高亮实体、建议动作和三轮对话。它是本地网页，无需安装软件或联网。双击 `校验数据.cmd` 可重新执行数据完整性检查。

**本包是“公开合成数据＋项目专用合成数据”，目前人工 gold 数量为 0。可以用于启动训练、调试和合成基准评测，不能把自动标签说成人工标注，也不能据此宣称真实场景准确率。**

## 已经有哪些数据

- **公开中文 PII 数据 8,000 条**：5,000 条正式文本、3,000 条聊天文本。来自 [wan9yu/pii-bench-zh](https://huggingface.co/datasets/wan9yu/pii-bench-zh)，作者声明为合成数据，许可标注 Apache-2.0。本包保留原始数据和说明，统一格式版本单独放在 `public/pii-bench-zh/external_test.jsonl`，没有混入我们的训练集。
- **项目实体识别数据 5,100 条**：14 类实体；包含 300 条无实体负例、600 条混合文本/表格材料，其他为有上下文的单类实体材料。划分为训练 3,400、验证 850、测试 850。
- **动作决策数据 1,440 条**：删除、本地聚合、泛化、代号替换、保留、暂停，各 240 条。划分为训练 960、验证 240、测试 240。
- **连续对话 360 组、1,080 轮**：每组 3 轮，覆盖改期限、恢复姓名请求、附件中的越权命令、指代歧义、名单去重与跨轮组合披露。训练 240 组，验证 60 组，测试 60 组。
- **小模型微调格式 7,620 条**：上述自制数据的另一种格式，训练 5,080、验证 1,270、测试 1,270。它们不是额外新增的独立样本，请勿与前述条数相加。
- **人工试标 92 个单元**：56 条实体材料、24 条动作材料、12 组三轮对话。全部取自训练部分，A/B 独立填写，第三人裁决。

准确数量和类别分布见 `stats.json`；自动质量检查结果见 `validation_report.json`。

## 最快使用方式

1. 要训练本地小型大模型：读取 `sft/train.jsonl`，用 `sft/validation.jsonl` 调参；`sft/test.jsonl` 留到最终测评。每行都有 `instruction`、`input`、`output`。`dataset_info.json` 提供常用 Alpaca 列映射。
2. 要训练实体识别模型：读取 `ner/train.jsonl` 中的 `text` 和 `entities`。需要逐字标签时，从区间派生 BIO；原始区间定义见下文。
3. 要复核实体标签：`doccano/*.jsonl` 是同一批数据的 `text`＋`label` 导入格式；独立试标优先用 `review/reviewer_A.jsonl` 和 `review/reviewer_B.jsonl`，避免一开始就看到建议答案。
4. 要使用当前项目的动作分类器：`legacy_actions/*.jsonl` 已按当前特征格式导出。只将 `train.jsonl` 传入训练器，并输出为新的候选模型文件；不要覆盖正在使用的权重。旧训练器会在训练文件内部再次分组验证，其输出分数不是本包独立测试集分数。
5. 要检查模型识别能力：`scripts/evaluate_ner.py` 可评估当前识别器，也可通过 `--predictions` 接收新模型的预测 JSONL。使用严格区间和类别匹配，不能与其他论文的宽松匹配指标直接比较。

建议先完成 92 个单元的人工试标，修正类别边界和决策口径，再扩大专项训练。**数量足够启动实验，不代表已经足够训练出可靠模型。**

## 文件说明

- `ner/`：项目实体识别数据。
- `policy/`：带任务、接收方、受信任上下文的动作决策数据。
- `dialogues/`：完整多轮会话，同一会话不会拆到不同集合。
- `sft/`：本地小模型指令微调格式，标签均为机器构造的候选答案。
- `doccano/`：实体区间复核的格式转换视图。
- `legacy_actions/`：现有 TF-IDF 动作模型可读的特征文件。
- `public/`：第三方原始数据、转换数据、来源说明和许可文件。
- `review/`：A/B 空白复核表、候选标注和详细流程。
- `scripts/`：重建、校验、导出及评测程序。
- `evaluation/`：当前识别器在自制验证集上的实测；不代表人工验收结果。

## 标注约定

区间采用 **Python Unicode 字符索引，左闭右开 `[start, end)`**；必须满足 `text[start:end] == entity.text`。不是 UTF-8 字节位置，也不是 JavaScript 默认的 UTF-16 索引。出现 emoji 时，浏览器端需先按 Unicode 码点换算。

14 类是 PERSON_NAME、PHONE、EMAIL、ID_CARD、BANK_CARD、STUDENT_ID、API_KEY、WECHAT、BUDGET、ORG、LOCATION、DORM、GRADE、SENSITIVE_ATTR。ORG 和 LOCATION 被识别出来不等于必须删除，是否保留由任务与权限决定。

只标具体值，不含字段名、冒号、前后空格。成绩标整个“85分”，宿舍标完整位置，敏感属性标完整描述。同一实体重复出现时每次都标；同一条记录里的 `entity_id` 用于对应关系，不是跨所有材料的真实人物标识。

公开数据还有 ADDRESS、PASSPORT、LICENSE_PLATE 三个扩展类别，当前应用尚未完整支持。家庭住址不能直接改成“可公开活动地点”标签。本包保留这些类型，不把它们强行合并到 LOCATION 后训练外发决策。

## 划分与防止数据混用

自制数据按整个模板族划分：v0—v3 训练、v4 验证、v5 测试；同源记录、同一对话及其格式转换始终保持在同一集合。实体识别包含 102 个模板族，动作包含 36 个，对话包含 36 个。已检查来源组、模板族和原文跨集合的交集为 0。

这是**模板构造数据**：同一模板仍有很多数值和实体替换变体，各集合仍共享生成逻辑、类别与词汇，因此零重复不等于真实分布独立。严肃评测仍须加入团队收集、获准使用且双人复核的新材料。

不要把 `public/external_test.jsonl`、`ner/test.jsonl` 或 `sft/test.jsonl` 混入训练；也不要在看过测试表现后反复修改模板并继续把它叫作独立测试。

## 合成值与质量限制

自制姓名和字段由程序构造，没有真实身份对应关系。手机号有常规格式，也有空格变体；它们未核验归属，可能偶然与现实号码相同，不能用于拨打或查人。邮箱使用 `example.invalid`，密钥明确以 `SYNTHETIC_NOT_REAL_KEY` 标识。

自制身份证使用虚构地区代码 `999999` 并构造校验位；银行卡使用 `000000` 开头的虚构前缀并通过 Luhn。这些只用于检测实验，不能视为有效证件或银行账户。因此还需要公开数据中的常见格式和后续授权材料补足分布差异。

动作标签按这里明确写出的合成任务构造；`acceptable_actions` 初始只列建议动作，人工裁决时可补充等价安全方案。对话数据描述目标行为，当前程序并未完整实现组合披露推断、自然语言指代消歧等能力。获得数据不等于这些功能已经完成。

## 重建与验证

在本文件夹下，使用 Python 3.12 或本项目便携 Python：

```powershell
python scripts/build_dataset.py
python scripts/validate_dataset.py
python scripts/export_legacy_actions.py
python scripts/evaluate_ner.py
```

重建不会发起网络请求；公开原始文件须已在包内。若 A/B 表已有任何人工修改，生成器会拒绝覆盖。人工作业请另外备份并保存裁决版本。

本次没有训练或替换现有模型，也没有自动上传这套数据到 GitHub。先把数据和口径复核清楚，再决定训练与发布版本。
