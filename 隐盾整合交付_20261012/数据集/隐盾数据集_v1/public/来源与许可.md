# 公开数据的来源与用途

## 本包实际下载的数据

作者：wan9yu。数据集：[PII Bench ZH](https://huggingface.co/datasets/wan9yu/pii-bench-zh)。

固定版本：`c350b94897af668517ff5de237d89f2ce2eaa6f0`。

原始文件为 `data/pii_bench_zh.jsonl` 和 `data/pii_bench_zh_chat.jsonl`，本包保持原内容，分别 5,000 和 3,000 条。作者声明全部为程序合成数据，标注许可 Apache-2.0，并在说明中限定研究与评估用途。本包将其独立保留用于外部合成基准，不混入专项微调训练集。原始说明见 `pii-bench-zh/README.md`。

2026-10-14 下载时原站连接被重置，实际传输使用公开镜像 `hf-mirror.com`，仍按上述固定版本路径获取。版本元信息保存在 `repository_metadata.json`。每个原始文件的 SHA-256 固定在 `scripts/download_public.py`，可重下和核对；这些是本次获取后的内容哈希，不是作者的数字签名。

作者标明的 Apache-2.0 许可全文随包保存为 `pii-bench-zh/LICENSE-2.0.txt`，文本来源为 [Apache 官方许可页面](https://www.apache.org/licenses/LICENSE-2.0.txt)。归属说明见 NOTICE.txt。本包不把第三方数据的许可扩大适用于自制数据或整个项目。

转换文件 `external_test.jsonl` 保留原文及区间，统一类别名称，并增加来源与未复核标记。全部 8,000 条通过字符区间检查；`quarantine.jsonl` 为空表示此次未发现需隔离的格式记录，不等于作者标签都经过了人工复核。

引用可写：wan9yu. PII Bench ZH: Chinese PII Detection Benchmark. Hugging Face, 2026. <https://huggingface.co/datasets/wan9yu/pii-bench-zh>。

## 以后怎么继续找数据

先查“语言、原始来源、标签类型、标注粒度、许可”，再决定能否用于当前任务。网页上可见并不代表可以任意打包再发布。

1. 中文姓名、地点、组织等通用识别：[CLUENER2020 官方仓库](https://github.com/CLUEbenchmark/CLUENER2020)。它是通用实体任务，不能直接当作“该不该对外披露”的动作标签。
2. 英文 PII/PHI 扩展：[Gretel PII Masking](https://huggingface.co/datasets/gretelai/gretel-pii-masking-en-v1)。数据卡标注英文、合成、Apache-2.0，可作为以后增加英文支持时的候选，本次未下载。
3. [AI4Privacy PII-Masking-300k](https://huggingface.co/datasets/ai4privacy/pii-masking-300k) 有专门的 [许可条件](https://huggingface.co/datasets/ai4privacy/pii-masking-300k/blob/main/LICENSE.md)，再分发要求另获书面许可，本包没有加入。
4. 你们的实际校园场景：由团队取得材料使用许可，先去掉不需要的真实标识再交给两人标注，按来源分组留出独立测试。这部分最能补上公开数据与真实使用场景之间的差异。

公开检索负责提供“文本和实体”；任务必要性、可接收范围和跨轮披露边界通常仍要由本项目标注，不能仅靠下载一个 NER 数据集解决。
