# 隐盾统一对话交付

只有一个对话入口。文字、材料上传、自动脱敏和连续追问共用同一会话历史与代号映射。

## 启动与使用

1. 保持 app 和 runtime 在同一文件夹内，返回交付根目录，双击“启动隐盾.cmd”。无需另装 Python。
2. 打开“打开隐盾.url”，或访问 http://127.0.0.1:8787/ 。
3. 选择身份和任务，输入消息或添加材料，点击“发送”。系统逐轮自动脱敏和复检。
4. 继续追问即可沿用上下文。侧栏可以将材料加入本轮或删除本机文件。
5. “新对话”或“清除对话”会清除当前历史和映射；材料文件需要单独删除。

旧 /chat 地址只跳转首页。刷新网页不自动恢复会话；闲置 30 分钟过期，最多 20 轮。
本轮最多 10 个附件，材料总计 24000 字符；不会静默截断历史。界面展示处理后的消息，可展开查看本轮隐私处理。

## API 是否接通

已有真实 API 接入代码，使用兼容的 /chat/completions 接口并发送完整对话历史。
当前实际配置为 LLM_MODE=mock，未配置 API Key，因此没有调用真实生成服务。
界面会区分离线演示、已配置待连接和本轮真实 API 成功。离线演示不是大模型回答。

接入真实服务：在本机 app/.env 设置 LLM_MODE=real，并填写 LLM_BASE_URL、LLM_MODEL 和 LLM_API_KEY，保存后重启。
地址和模型名称以自己已开通的服务为准。先用不含敏感信息的消息验证连接。
真实供应商连通性与回答质量尚未验收；本轮 4 项 HTTP 模拟检查只验证客户端协议行为。

## 内容位置

- app：源码、前端、配置、已训练模型、合成数据、训练与测试脚本。
- runtime/python：Windows x64 Python 3.12.6 与所需依赖，保留许可证。
- 报告：统一对话版本项目报告、人工复核方案及可填写记录页。
- 验证结果：测试 XML、浏览器检查、合成评测与模型信息。
- 运行验证.cmd：运行本地测试与评测。重新训练.cmd：用现有合成开发集重训。

## 当前边界

本地动作模型是 TF-IDF 加逻辑回归，模型决定动作，安全检查只能放行或暂停，不回退旧规则决策。
缺少人工复核的独立验收集。按方案先试标，再锁定 12 份材料的 24 个任务变体和 6 组三轮对话；这是计划，不是已经完成的验证。
上传解析文本在 app/data/uploads，可能包含原值；会话映射和原值匹配信息存在内存。共享前移除密钥、上传材料和运行输出。
已在本机验证，尚未在另一台干净电脑验收。可选 GPU NER 不在当前运行路径内，未打包其权重与依赖。
