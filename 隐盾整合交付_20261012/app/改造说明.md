# 隐盾模型决策改造说明

本文记录模型决策改造阶段。当前交付已改为统一对话入口，最新测试为 57 项回归通过；产品操作与当前限制以根目录“先读我”和“报告”文件夹内的新文档为准。

本次以用户提供的桌面源码为基础，移除了旧版规则优先的动作决策和在线规则兜底。当前执行方式为本地动作模型选择处理动作，安全检查只能接受或暂停。此次没有重训大语言模型；本地模型仍是 TF-IDF 加逻辑回归，云端模型负责处理经过防护的内容。

## 已完成

- 用模型唯一最高概率决定删除、聚合、泛化、代号替换、保留或暂停，不再按动作代价或任务偏好排序。
- 缺失、旧版或损坏权重不能进入决策；模型异常、无效概率、并列最高概率和非法建议均暂停。旧 `necessity_lr.joblib` 不再加载，新权重为 `models/necessity_action.joblib`。
- 任一片段暂停时，整个请求停止，不能把其他段落继续发出去。保留权限检查、接收方约束、任务禁止项和发送前复检。
- 白名单不能覆盖其他接收方的禁止项。外发前检查包含系统提示和正文的完整内容；结果展示被拦截时清空展示字段。
- 识别器异常、无有效识别器或实体坐标无效时停止处理，不能当作没有敏感信息。重叠片段覆盖完整区间，跨句实体不会因分段而丢失。
- 日期泛化移至按原始坐标处理敏感片段之后，避免后续实体替换错位。
- 页面新增任务要求输入，贯通本地模型特征；明确显示模型就绪和暂停原因。更新启动、训练、测试和打包说明。

## 验证结果

验证日期：2026 年 10 月 12 日。

- 38 项原有冒烟检查全部通过。
- 39 项新增回归测试全部通过，另有 27 个参数化子检查通过。覆盖模型影响动作、失效暂停、安全拒绝、权重兼容、按源案例分组、接口传参、识别故障与坐标安全。
- Python 编译检查和前端 JavaScript 语法检查通过。
- 使用现有开发案例生成 11,418 个分段与接收方训练变体，按源案例分组留出验证；训练组与验证组无案例 ID 重叠。标签来自明确标注的离线规则启动基线，不是人工金标。
- 当前 90 个合成测试案例中，82 个通过启发式任务完成检查，8 个被拦截；已发送内容按当前金标值与禁止类别口径未发现泄露。7 个拦截由输出复检命中姓名触发，1 个由模型建议保留直接标识符而被安全检查拒绝。这些拦截尚未逐条人工标注，不能报告为误拦率。
- 测试集未参与模型拟合，但在本轮排查中被重复查看；开发集和测试集仍共享合成方式。这不是独立真实场景验收结果。
- 完成率和关系要素保留率仅作本地代理指标；目前没有验证云端最终回答的质量，没有运行真实云端 API 测试。

关闭模型后全部暂停，只能证明故障时停止发送，不能证明模型质量优于固定规则。回归测试另以相同输入、不同模型评分检验动作是否随模型变化。

## 仍需改进

第一优先级是人工复核数据。对同一材料标注不同任务要求、不同接收方下的正确动作及是否应暂停，按来源文档和模板隔离训练、验证与测试。当前模型主要学习合成标签，新增任务描述特征不代表已具备自由任务语义理解。

第二优先级是混合实体与姓名复检。当前按句决策，同一句的姓名、电话和预算仍共享一个动作；后续可训练实体级动作并保留跨句人物关系，减少整段过度处理。先人工核对这次 8 个拦截，再用开发集修正问题，保留新的测试集作为最终验收。

第三优先级是改进评测。补充严格实体边界、原值残留、真实人物与事项对应、下游任务完成质量，并按接收方与类别分别统计。报告中的区间相交 F1 无法单独证明完整遮住敏感值；各类分数取中位数作为门槛也无法单独证明风险受控。若后续引入置信度拒绝，应在独立验证集上检查概率校准，再依据误放行与误暂停的代价确定阈值。参见 [scikit-learn 概率校准说明](https://scikit-learn.org/stable/modules/calibration.html)。

第四优先级是部署身份。当前界面选择身份和会话 ID 属于本机演示机制；多用户部署需要把身份、上传材料和映射表绑定到真实登录会话。此项未在本轮扩展实现。

## 复现

推荐使用 `requirements-lock.txt` 中本轮验证过的依赖版本，尤其是读取随包提供的 sklearn 模型时。普通安装和从头训练见 README。全部测试使用合成材料，没有将用户报告或项目材料发送给云端模型。

```powershell
python -X utf8 -m pip install -r requirements-lock.txt
python -X utf8 tests/test_smoke.py
python -X utf8 -m pytest tests --ignore=tests/test_smoke.py
python -X utf8 eval/run_eval.py --split test
python -X utf8 run.py
```

完整评测记录位于工作副本的 `outputs/eval_result.json`。分发包排除运行输出、密钥、用户上传材料与虚拟环境，并包含新的必需动作模型。
