# 第二台 Windows 电脑验收步骤

执行人可以是任意一名团队成员，约 20–30 分钟。使用已校验的 ZIP，先做离线检查；不需要在第二台电脑配置密钥。

1. 将 ZIP 完整解压到可写目录，保留 app 与 runtime 的相对位置。记录 Windows 版本、解压路径和执行日期。
2. 双击“启动隐盾.cmd”，保持控制台窗口开启。若安全软件提示，交由该电脑负责人判断，不关闭系统防护。
3. 双击“打开隐盾.url”，确认页面只有一个对话入口，API 状态明确显示离线演示。
4. 选择学生组织负责人和会议纪要，输入虚构文本：“负责人：张明。事项：海报设计。期限：周五。” 发送后检查姓名是否变成代号。
5. 再发：“负责人：张明。期限改为下周一。” 检查沿用代号和前文历史。离线模拟只评价流程，不评价回答质量。
6. 新建一个仅含虚构内容的 txt，上传后检查加入本轮、移出、重加和删除本机文件。清除对话，确认历史清空。
7. 双击“打开人工复核.cmd”，确认可以读到 9 个试标单元。若只做设备验收，不要把练习填写结果作为正式人工复核提交。
8. 双击“运行验证.cmd”。保存最终通过/失败信息；若报错，记录操作步骤和错误截图，不截取密钥或真实材料。

验收记录：执行人代号____ 日期____ Windows 版本____ 启动成功____ 两轮对话____ 附件管理____ 清除会话____ 复核页____ 自动化验证____ 问题描述____。

如需真实连接，由账户负责人只在该电脑本机配置密钥和额度，改为 real 后重启，再用“检查API连接.cmd”测试一次公开短句。不要将填写密钥后的工作目录重新公开打包。
