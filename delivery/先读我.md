# 隐盾当前本机版

更新：2026-10-17。全新克隆先在仓库根目录运行 `powershell -ExecutionPolicy Bypass -File .\delivery\安装开发环境.ps1`，并放置独立保存的 `app/models/reviewed_ner` 模型产物；详情见[从 GitHub 安装与验证](../docs/从GitHub安装与验证.md)。就绪后使用本目录的“启动隐盾.cmd”，或上一级同名入口。默认地址 http://127.0.0.1:8789/，名单核对页面 /notice。

当前入口加载 `app/models/reviewed_ner` 的人工 gold BERT（BIO 约束解码）和 `app/models/necessity_action.joblib` 的 segment_coverage_v2 动作分类器，自动选择 CUDA / CPU，并强制本地模拟回复。现有 .env 没有被改写；在此入口下填写 API 密钥也不会自动启用真实生成。

名单核对只在本机处理。生成通知时只提交单独填写的公开活动名称和通知事项，不提交名单、附件或聊天历史。仍需用户结合原文核对识别结果；系统不会验证联系信息真实性，也未向任何人发送通知。

## 常用入口

- 启动隐盾.cmd：启动；附加 --check-only 只验证模型与依赖。
- 打开隐盾.url：打开默认网页。
- 停止隐盾.cmd：停止默认端口中由本项目绝对路径启动的进程；其他进程不自动结束。
- 运行验证.cmd：本地 smoke + pytest，不调用真实生成服务，不运行封存集评分。
- 运行Python.cmd：优先使用本机 runtime/training_env；全新克隆使用安装器建立的 app/.venv。
- 检查API连接.cmd：真实 API 连接自检，仅供后续真实联调使用。

模型清单在 [app/models/ACTIVE_MODELS.json](app/models/ACTIVE_MODELS.json)。实验结论见上一级 docs；AI 接手计划在 [AI_EXECUTION_PLAN.md](../AI_EXECUTION_PLAN.md)。

## 保留范围

源码、测试、当前模型、训练底座、人工 gold、复核工具、最终验证证据和最近提交材料均保留。未采用候选只保留来源、参数、指标与取舍原因，大权重已移除。个人课程资料已移到上一级“个人资料”。

原开发机的 runtime 不随 Git 分发。全新克隆可以安装基础依赖并运行软件回归，但缺少 reviewed_ner 权重时维护模式的预检会明确失败；完整版本尚未通过第二台干净电脑验收。现有提交材料仍需最终同步，不能把模拟回复写成真实外部模型验证。
