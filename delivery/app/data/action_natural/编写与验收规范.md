# 自然文档动作数据：生成与拒收规范

本目录是独立编写的虚构文档源稿，不是词槽模板库。`part_*.json` 可重复打包用于复现；重复打包不算新增数据。所有机器标注待人工复核。

## 给后续生成模型的任务

请先设计新的业务矛盾、资料流转过程和文档结构，再写原文。不要先选动作，再在用户指令里把答案说出来。每个新批次须同时提供此前批次的文档清单与场景摘要；不能只看上一份提示词从头重复。

1. 每批至少24篇完整材料，至少8种文体。把群聊、邮件往返、工作便笺、访谈、说明、草稿更正、流水记录、问答等实际形式混合。长度随信息量变化；不要用固定开头、结尾或固定实体组合凑数。
2. 用户要求以简短自然表达为主，例如“明早照这个跟进”“把能发的那版整理出来”。正文和前序对话要提供足以推断用途、受众、时间和相关性的事实，不写“本题应保留负责人、删除电话”这种答案旁白。
3. 一篇至少3个完整决策片段，通常有2–4种不同处置。让干扰信息、有效事实、旧版本、新补充交错出现；别每篇都固定放负责人、电话、机构三件套。保留事实可能需要原值、代号、类别或本机统计，不能只学敏感词删除。
4. 覆盖指代、职责变更、旧邮件引用、旁听人与执行人区分、同名不同人、记录数与人数、用途变化、权限已核验与未知、缺失关键事实。有足够上下文的短指令应可推断；只有缺口会实质改变结果才暂停，并给出可回答的澄清问题。
5. 少量同文同任务的上下文对照用于检查是否阅读上下文。两份同 `context_pair_id`、同 `scenario_group`、同拆分，改变真实背景事实而不是直接提示动作。其余近重复材料拒收。
6. 先确定语义场景族，再拆分；同材料、改写、派生、同一事件不同任务全部同组。测试也是 AI 合成材料，不冒充真实独立盲测。

## 源稿格式

每个 `part_*.json` 是文档数组。文档字段包括 `document_id`、`scenario_group`、`split`、`document_type`、`task`、`recipient`、`identity`、`task_description`、`context`、`text`、`phenomena` 和 `decisions`；对照额外用 `context_pair_id`。

`decisions` 中每项含 `segment`（正文中的连续完整片段）、`entities`（text/category）、`action`、`minimum_representation`、`required_facts`、`reason`、`evidence`（正文或背景原句）；PAUSE 还需 `clarification_question`。不要将建议动作、判断理由、现象标签或澄清答案放入用户输入。

动作沿用现有片段接口。以 `m6_transform/anonymizer.py` 的实际实现为准：DELETE 删除标注实体并保留其余文字，不能承诺整段无关叙述消失；LOCAL_AGGREGATE 删除实体明细、保留非实体文字，并另追加聚合结果；PSEUDONYMIZE 将姓名/机构代号化，并删除其他标注实体。GENERALIZE 当前把机构/地点替换为校内泛称，不支持任意地域或行业粒度。混合实体按真实转换能力核对；无一种动作能满足全部要求时登记能力缺口，不编造可执行标签。实体范围由构建器自动计算，重复实体全部标出。当前是给定实体的动作研究，不能声称验证了自动识别或真实分段能力。

## 验收与运行

默认入口现在是自然文档，旧336模板须显式指定 `--legacy-template-pack` 才可复现。构建器检查语义族隔离、实体范围、动作/表达一致、当前硬约束、正文证据、文体覆盖、指令泄露、整篇多动作，以及遮盖已标注实体和数字后的字符三元组 Jaccard 近重复（阈值0.65）。显式动作标签或答案提示会在任务、背景、正文三个模型输入字段中一起检查。正常业务背景、真实权限事实可以提供，代号化/删除等解题结论只放机器建议区。统计样本应提供完整名册与口径，避免同时在正文抄出待算答案；已有可信汇总时，名单可能应直接删除。以上是工程筛选指标，不是自然度或学习效果的证明；仍需人工抽查未标实体、可执行性与事实关系。

在 delivery/app 下运行：

```powershell
../runtime/training_env/Scripts/python.exe -B -X utf8 scripts/build_action_review.py --out ../../03_数据与人工复核/新的版本目录
```

默认自动检查输出父目录下已有各包的 `documents.jsonl`。后续新批次使用新源稿目录，其他位置的既有材料逐个通过 `--history` 追加。只想复现本版时显式传 `--rebuild-frozen`，产物会标记“不算新数据”。例如：

```powershell
../runtime/training_env/Scripts/python.exe -B -X utf8 scripts/build_action_review.py --source-dir data/action_next --history ../../03_数据与人工复核/任务必要性复核_自然文档_v3_20261029/documents.jsonl --out ../../03_数据与人工复核/新的版本目录
```

输出保留原稿、机器草稿、隐藏建议的人工题目、来源哈希及质量报告。首次复核按6份完整训练材料选取，覆盖不同文体和处置，不固定循环28题。

训练前必须核对实际复核来源；已看过模型建议的确认和独立盲标分别记录。比较至少包括任务/上下文消融、同文上下文反转一致性、按场景族留出和逐篇多信息处理完整性，不能以增加行数或合成准确率宣称落地效果提升。
