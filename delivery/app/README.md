# 隐盾应用

新增“识别与集成”页面提供本机诊断和受控工具确认。Presidio、NeMo、LiteLLM、Dify 和 Lakera 的配置、验证范围及依赖见 [融合接入说明](../integrations/README.md)。

应用只有这一份实现。入口为仓库根目录的“启动隐盾.cmd”，端口 8787。代码与本机 GLiNER 权重都在本目录内；密钥从 .env 读取。

对话、预览、单次运行共用 processing.py 和 material_processing.py；GLiNER 单例加载，批量处理材料窗口。格式标识符由正则与校验规则识别，语义类别由 GLiNER 与词典补充。动作模型 feature v3 与其权重配套，不兼容的候选不能直接替换。

Campus NER 已移除。eval/reviewed_ner.py 仅由离线 BERT 比较脚本显式使用，在线识别管线没有该模型开关。模型清单见 models/ACTIVE_MODELS.json；安装和验证命令见根目录 README。

config、web、tests 分别保存配置、前端与回归；data/uploads、outputs、.env 和本机大权重被 Git 忽略。/api/health 用于就绪检查，/api/metrics 返回有界的阶段耗时统计。

## 生成服务与组织策略

默认 `LLM_MODE=real`。已有的 `auto` 配置同样走真实生成。缺少密钥或请求失败时，界面显示原因，本轮暂停。本机全表统计无需生成服务。可用启动脚本的 `--offline` 参数显式切换模拟生成。

在应用目录使用启动器同一 Python 运行 `python -m llm_shield.api_check` 可检查配置。加 `--connect` 会发一条固定公开短句测试实际连接，可能产生少量 API 费用。

如已有 [LiteLLM Proxy](https://docs.litellm.ai/docs/simple_proxy)，可将 `LLM_PROVIDER=litellm`、`LLM_BASE_URL=http://127.0.0.1:4000`、`LLM_MODEL` 及 `LLM_API_KEY` 分别设为代理标识、地址、部署别名及虚拟密钥。隐盾先检查完整消息，再交由代理选择上游。远程生成地址须使用 HTTPS。代理侧的日志、路由及回退服务按部署方策略配置。

可选的 [OPA](https://www.openpolicyagent.org/docs/rest-api) 为组织提供额外的授权层。在应用目录执行 `opa run --server --addr 127.0.0.1:8181 config/opa`，再在 `.env` 设置 `SHIELD_EGRESS_POLICY=opa` 并重启。样例策略只许可列出的会议纪要操作。部署前按组织职责修改许可清单。隐盾只把角色、任务、接收方和操作标识交给回环地址上的 OPA。模型输入、对话回答、授权展示和工具外发分别查询许可。服务故障、超时和未知许可均暂停对应操作。本地权限及载荷复检继续生效。

多轮对话默认将历史消息与本轮动作评分隔离。通过复检的历史仍可送给生成服务，支持追问。

## 2.0 候选版

用仓库根目录的“启动隐盾.cmd”启动，首页可进入下列工作台。

- **表格工作台**。上传 XLSX、CSV 或 TSV 时请选择活动统计用途。选择主表后可以组合等于和不等于条件，按字段分组，按非空唯一键去重，也可关联一张以非空键唯一的辅助表。关联只计算匹配成功的主表记录，未匹配数单独显示。记录合计与按身份键去重的合计分开。各组复用同一键时，分组合计可能大于全局合计。
- **接收方版本**。上传或选择已授权材料，为不同接收方生成本机预览。展示版按原有规则判断能否恢复代号，外发版按对应工具边界重新检查。通过检查的外发版可下载为新排版的 Word。下载时重新计算并验证内容与显式预览一致。生成的文档由通过检查的文本构建，原文件的样式、批注及附件不参与构建。
- **材料解析**。CSV 和 TSV 的空表头、重复表头及超出表头的列会提示修正。可读取的 PDF 文本标明页码。有内容但没有文本层的页面会提示先做 OCR。

表格汇总和接收方预览均在回环地址运行。分组可能显示源字段值，下载的统计 CSV 和 XLSX 属本机结果，分享前须按接收方重新处理。工作台使用现有单机身份预设，组织身份认证和项目隔离仍属后续建设。上传的临时材料默认 30 分钟失效，服务端每次统计或导出都重新检查用途与来源。

- **对话统计追问**。保留原表附件，先问“网络空间安全专业有多少人”，再问“再排除职责为带队助教”，最后问“按车辆分组”。每次按同一张全表重算，回显口径。源材料失效、字段不明确或多表合并未指定时停止推断。对话外的组合条件、关联、去重和 Excel 下载在表格工作台完成。
- **扫描件核对**。为启动器使用的 Python 安装 “requirements-ocr.txt”。接收方版本页面选择 PNG、JPEG 或 PDF 后点击“识别扫描件”，在可编辑草稿中核对逐页结果。草稿会提示低置信行数和无结果页。单文件上限 5 MB，PDF 最多 20 页。默认使用 [RapidOCR 本地模型](https://github.com/RapidAI/RapidOCRDocs/blob/main/docs/install_usage/rapidocr/install.en.md) 和 [PDFium 渲染](https://pypdfium2.readthedocs.io/en/stable/python_api.html)。识别接口返回文本与坐标，不保存原始扫描件或创建材料库记录。
- **项目协作**。设置 SHIELD_WORKFLOW_ADMIN_TOKEN 后，从首页进入项目管理。用现有项目接口在本机求解并核验分配，签发和撤销供应商凭证，按候选版本运行封存验收。供应商通过独立表单输入两类凭证完成一次核销。本轮供应商表单使用在线服务，刷新前可复用同一签到事件重新提交。

安装可选 OCR 支持（在仓库根目录运行）。

```powershell
.\delivery\运行Python.cmd -m pip install -r delivery/app/requirements-ocr.txt
```

当前交付范围是本机工作台和项目协作候选版。Word 导出采用重新排版。保留原版式的文件脱敏、逐实体调整动作、手机扫码与离线补传、组织身份隔离和独立验收尚未进入发布范围。
