`annotation` 里只填这些字段：

| 字段 | 填什么 |
| --- | --- |
| `canonical_action` | 六类动作之一。拿不准就留空 |
| `required_facts` | 你靠哪句话、哪个接收方、哪条权限做出判断 |
| `adjudication` | 能判断就写「已填写」。不能判断就写「待裁定」 |
| `notes` | 可选 |
| `annotator` | 填写人 |
| `annotated_at` | 日期 |

六类动作只能是：`DELETE`、`LOCAL_AGGREGATE`、`GENERALIZE`、`PSEUDONYMIZE`、`RETAIN`、`PAUSE`。

## 六个动作是什么意思

- `DELETE`：这条信息不出现在给该接收方的结果里。
- `LOCAL_AGGREGATE`：只留下数量或统计，不留下是谁。
- `GENERALIZE`：留下大致水平或角色，不留下原来的值。
- `PSEUDONYMIZE`：换成稳定代号。不同的人要还能分开。
- `RETAIN`：这个接收方可以看到原来的值。
- `PAUSE`：先停下来。接收方、权限或任务要求不够，或者做下去会越过该接收方的权限。

拿不准时不要猜。动作留空，`adjudication` 写「待裁定」，在 `required_facts` 里写卡在哪。

判断时看三件事：用户这句话到底要完成什么，接收方是谁，这个身份能不能把这条信息给这个接收方。同一段原文如果列了两次，接收方或任务说明不同，要分开判断。
