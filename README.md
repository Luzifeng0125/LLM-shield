# 隐盾 LLM-Shield

隐盾是面向高校活动、学生组织和小组协作的隐私保护工作台。它在本机读取材料、识别敏感信息并按任务和接收方权限处理内容。表格统计在本机执行，只有通过检查的任务内容才会发给外部生成服务。

当前分支是 **2.0 候选版**，已支持表格连续追问、扫描件核对、按接收方生成 Word，以及资源分配、供应商签到和封存验收。

## 快速启动

Windows 下双击 [启动隐盾.cmd](启动隐盾.cmd)，或在仓库根目录运行以下命令。启动后打开 [本机工作台](http://127.0.0.1:8787/)。

```powershell
& '.\启动隐盾.cmd' --check-only
& '.\启动隐盾.cmd'
```

首次克隆请先按 [安装与验证说明](04_技术文档/从GitHub安装与验证.md) 配置 Python、GLiNER v3 权重和本机的 `delivery/app/.env`。默认启用 GLiNER 并自动选择 CUDA 或 CPU。对话生成默认使用真实配置的 DeepSeek，连接或配置失败时会报告原因。本机表格计算无需生成服务。

扫描件识别需要额外安装本机 OCR 依赖。用应用启动器对应的 Python 安装后重启。

```powershell
& '.\delivery\运行Python.cmd' -m pip install -r delivery/app/requirements-ocr.txt
```

## 2.0 候选版功能

| 入口 | 可以完成的任务 |
| --- | --- |
| 对话 | 上传表格后先问“网络空间安全专业有多少人”，保留原附件再问“再排除带队助教”“按车辆分组”。系统按同一张全表重算，回显记录数和统计口径。 |
| 表格工作台 | 组合条件、关联两张表、分组、按非空唯一键去重。可下载 CSV 或带来源和统计口径的 Excel。分组汇总供本机核对，分享前应按接收方重新检查。 |
| 接收方版本 | 预览老师、同组成员与外发端各自获准查看的内容。通过外发检查的版本可下载为重新排版的 Word，下载时会重新校验。扫描 PDF、PNG 和 JPEG 可先转换成可编辑的逐页草稿，对照原件核对后继续。 |
| 项目协作 | 在本机求解并核验资源分配，签发或撤销供应商凭证，核销签到以及运行封存验收。项目管理使用 `SHIELD_WORKFLOW_ADMIN_TOKEN`，配置见 [项目工作流试运行说明](04_技术文档/项目工作流试运行.md)。 |

隐盾先校验身份与材料用途，再执行本机统计，或对生成所需内容做敏感识别、动作决策、脱敏和外发复检。代号映射留在本机，授权展示与工具外发分别检查。详细配置和限制见 [应用说明](delivery/app/README.md)。

## 验证状态

2.0 候选版代码提交 `355110a` 在装有 GLiNER 的环境中通过了 **38 项冒烟检查和 472 项回归**。另有 1 项多轮用例因 GLiNER 在部分代号上下文中将“准备海报”误识为敏感属性而被拦截。合成样本已验证中文图片和扫描 PDF 的本机 OCR，以及三轮表格追问。

正式发布还需完成独立验收、原版式脱敏、逐实体调整动作、手机扫码与离线补传、组织级身份隔离。回归与运行预检命令见 [安装与验证说明](04_技术文档/从GitHub安装与验证.md)。
