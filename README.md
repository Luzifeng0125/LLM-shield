# LLM-shield · 隐盾

隐盾把**材料上传、敏感信息处理和连续追问**放在同一个**本地**对话入口中：
本地完成「识别 → 决策 → 转换」，通过权限与外发安全校验后，才把**脱敏后的文本**交给云端生成服务。

全过程在三个边界（发给模型的请求 / 展示给用户的结果 / 提交给工具端的内容）上做泄露观测。

## 运行

**已有本地便携包**：双击 `delivery/启动隐盾.cmd`，打开 <http://127.0.0.1:8787/>。

**从 GitHub 克隆**（需要 Python 3.12）：

```powershell
git clone https://github.com/Luzifeng0125/LLM-shield.git
cd LLM-shield
powershell -ExecutionPolicy Bypass -File .\delivery\安装开发环境.ps1
.\delivery\启动隐盾.cmd
```

安装脚本创建项目虚拟环境并安装锁定依赖；只在不存在时从 `.env.example` 生成 `.env`，默认离线演示。
若要调用真实 API，在 `delivery/app/.env` 设置 `LLM_MODE=real` 并填写 `LLM_API_KEY`。
**不要把密钥提交到 Git**（`.env` 已被 `.gitignore` 拦截）。

仓库只保留约 1 MB 的动作模型（`models/necessity_action.joblib`），
**不含**便携 Python、虚拟环境或 GPU 模型权重。

### 手动启动

```bash
cd delivery/app
python run.py --host 127.0.0.1 --port 8787
```

## 敏感信息识别（v3）

识别层由三路检测器并行组成，结果经统一合并策略归并：

| 检测器 | 负责类别 | 说明 |
|---|---|---|
| 正则规则 | 格式类 9 类 | 带校验位验证：身份证 GB 11643、银行卡 Luhn |
| 词典 + 上下文 | 姓名 / 敏感属性 / 列名 | GLiNER 启用时关闭其机构/地点规则（贪婪正则边界过宽） |
| **GLiNER（可选）** | 除身份证外 13 类 | 基于 `gliner_multi-v2.1`（Apache-2.0）微调 |

启用方式：`delivery/app/.env` 中设 `SHIELD_USE_GLINER=true`（默认 `false`）。

### 三个关键工程点

1. **字符级中文分词**：GLiNER 默认分词会把整串连续中文当成一个 token，导致实体边界错位。
   项目改用字符级分词器（`m2_detect/char_splitter.py`）。
2. **两趟推理**：全部标签一次性推理时，标签竞争会稀释稀疏类别（如敏感属性）的分数；
   拆为「语义 5 标签 + 格式 8 标签」两趟。
3. **合并策略**：同类别重叠取置信度更高的精确边界；跨类别冲突按检测器可信度排序（正则 > 模型），
   避免模型的高置信猜测覆盖带校验位的正则结果。

### 实测

| 测试集 | 微平均 F1 |
|---|---|
| 人工 gold 测试集（124 实体） | **1.0000** |
| 未见模式留出集（178 实体，基线 0.8000） | **0.9382** |

> 该指标基于**合成/半合成数据**，不能直接当作真实场景的隐私保护准确率。

### 模型权重不在仓库内

因体积（约 1.1 GB）且依赖特定路径，GLiNER 权重未纳入 Git。自行准备步骤：

1. 取 `urchade/gliner_multi-v2.1` 与 `microsoft/mdeberta-v3-base` 的 tokenizer；
2. 用 `delivery/app/` 下的训练脚本微调；
3. 放到**纯 ASCII 路径**（如 `D:/project/models/gliner_v3`）——
   sentencepiece 的 C++ 后端无法打开含中文的路径；
4. `.env` 中设 `SHIELD_USE_GLINER=true` 与 `SHIELD_GLINER_MODEL_DIR`。

## 当前实现边界

- **动作决策**：TF-IDF + 逻辑回归分类器。模型选择动作，安全校验**只接受或暂停，不做规则动作兜底**。
- **跨轮状态**：当前为单次请求流水线；跨轮别名一致性、累计计数、歧义指代暂停尚未实现。
- **细粒度决策**：当前每个决策单元输出一个动作；「同段内姓名假名化 + 电话删除」的按类别细粒度尚未实现。
- **组合式重识别**（如唯一奖项 + 组织 + 代号联合可重新识别到人）尚未覆盖。
- 提交材料中的本地大模型部分标注为"方案假设"，未完成的真实 API、训练及人工评测结果标注"待补"。
- 合成弱标签分数和离线测试**不能**当作真实隐私保护准确率。
