# LLM-shield · 隐盾

隐盾把材料上传、敏感信息处理和连续追问放在同一个本地对话入口中：本地模型选择处理动作，通过权限与外发安全校验后，再调用云端生成服务。

本仓库于 2026-10-14 整理为一套维护中的代码。历史文件夹名称中的日期保持不变，避免破坏已有启动入口。

## 运行

已有本地便携包：双击 `隐盾整合交付_20261012/启动隐盾.cmd`，打开 <http://127.0.0.1:8787/>。

从 GitHub 克隆：先安装 Python 3.12，在 PowerShell 中运行：

```powershell
git clone https://github.com/Luzifeng0125/LLM-shield.git
cd LLM-shield
powershell -ExecutionPolicy Bypass -File .\隐盾整合交付_20261012\安装开发环境.ps1
.\隐盾整合交付_20261012\启动隐盾.cmd
```

安装脚本创建项目虚拟环境并安装锁定依赖；只在不存在时从 `.env.example` 生成 `.env`，默认离线演示。若要调用真实 API，在本机 `app/.env` 设置 `LLM_MODE=real` 并填写 `LLM_API_KEY`。不要把密钥提交到 Git。仓库保留约 1 MB 的当前动作模型，不包含便携 Python、虚拟环境或可选 GPU 模型。

## 验证与人工复核

双击 `运行验证.cmd` 运行离线冒烟、回归和合成评测；该脚本使用 mock 模式。双击 `打开人工复核.cmd`，两位成员独立填写并导出，第三位成员裁决分歧。连接真实 API 请单独运行 `检查API连接.cmd`，它会发送一条固定公开短句。

## 当前实现边界

当前动作模型是 TF-IDF 与逻辑回归分类器；敏感信息识别使用格式检测及上下文方法。本地专项小型大模型仍是待训练、待接入的目标方案。模型选择动作，安全校验只接受或暂停，不提供规则动作兜底。

提交材料中的本地大模型部分标注为“方案假设”，未完成的真实 API、训练及人工评测结果标注“待补”。合成弱标签分数和离线测试不能当作真实隐私保护准确率。

本机的 `参考资料/` 保存原始需求；其他课程/项目文件保持原样，均不属于本仓库。
