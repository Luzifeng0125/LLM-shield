## 当前应当知道

1. 最新训练的是11月2日上下文增强候选（特征版本5）；同日任务需求候选使用版本4。31条人工裁定上，硬约束后分别匹配19条和22条，默认模型匹配17条；详见[人工评测报告](04_技术文档/校园必要性模型独立人工评测报告_20261102.md)。候选均未晋级，默认权重未替换。
2. 真实 GLiNER 权重仍未补齐，标准启动可能明确报告缺少权重；这不是文件整理新增的模型问题。校园在线入口有活动通知 `activity_notice`、班级协作 `class_coordination`，以及一则联系通知 `contact_notice`（姓名和电话占位后授权恢复）。其余校园任务只有离线规则。说明见 [校准说明](03_数据与人工复核/校园最小披露_校准首批_20261031/README.md)。
3. 最新校园材料为 [11月2日盲标包](03_数据与人工复核/校园必要性盲标_20261102/开始这里.md)，12篇31条，最终裁定已冻结。旧[上下文长材料 v4.1](03_数据与人工复核/上下文长材料_v4_1_20261030/开始这里.md)为27篇122处AI草稿；原138题人工辅助二审和旧336条模板历史保留追溯。根目录人工复核快捷入口仍指向历史v4.1，不会覆盖已完成标签。

5. 提交材料是编辑基础，文件名含“最终”不代表已经覆盖最新研究证据。
6. GitHub分发小型动作模型和配套源码；本地密钥、运行环境、上传材料、人工返还归档及GLiNER大权重不入库。模型上传不代表部署或完成真实识别验收。
