## 本轮交付

- 运行包使用 Git 管理的文件清单，包含应用、配置、网页、合成材料与默认动作权重，每个文件带 SHA-256。生成数据、训练模块、测试、私有上传和输出归档留在对应工作目录。包内提供独立启动和安装说明。
- Presidio 的识别依赖与离线算子对照依赖分别安装。核心锁定的 NumPy 改为本机已验证的 2.4.6，与 Presidio 要求的低于 2.5 一致。
- Presidio 模式具有独立版本，配置阶段拒绝重名识别器和同类别重复正则。
- NeMo 公共规则继续生效，六个检查位置可以分别追加规则。模型回答、知识片段和工具响应通过正常调用路径进入对应检查。
- 旧架构文档已标明日期，技术导航提供当前运行架构和下一代设计入口。

## 验证

本轮 23 项定向测试通过，覆盖识别器去重、普通网关的边界选择、配置兼容、运行包内容与哈希、原有 Dify 和工具行为。默认配置的回归通过 489 项及 33 项子检查，另有 1 项旧多轮用例因 GLiNER 将普通事项误识为敏感属性而暂停。38 项独立冒烟检查通过。三个使用 sys.exit 的独立脚本与 pytest 用例分别运行，避免在收集时退出。

空目录解压运行包后，复用本机已有 Python 环境和 GLiNER 权重，完成模型加载、网页访问、名单核对和全表统计验证。这个验证覆盖包的完整性与基本功能，新机器安装仍需单独验收。

运行包生成命令如下。

```powershell
& '.\delivery\运行Python.cmd' delivery/app/scripts/make_release.py --profile runtime --version 2.0-integration --out local/releases/shield-runtime-2.0.zip
```

运行包的 GLiNER 完整目录需单独配置。研究数据、历史权重和申报材料仍可从对应源码目录取得。单个文件的内容相同并不证明它在两版研究快照中可以删除。
