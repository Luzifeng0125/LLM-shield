# 本地必要信息处理与授权结果补全

日期：2026-11-02。本阶段最后一项功能。活动模型、硬约束、31 条冻结标签和《校园必要性模型独立人工评测报告_20261102.md》没有改。

## 两条动作分开记

n04 的用户要求是：整理会议纪要，人员和事项要能对上，印刷费 6400 元只交代到千元这一档。

| 层级 | 动作 | 含义 |
| --- | --- | --- |
| 任务必要性 | `GENERALIZE` | 本地把 6400 元收成「约六千元」 |
| 当前外发边界 | `WITHHOLD` | 外部模型不接收原始金额、泛化金额或映射表 |

泛化后的预算仍然是预算。外部模型的 `forbidden` 仍包含 `BUDGET`，这条禁令没有放宽。本地 `GENERALIZE` 不等于云端可以接收该金额。

## 修复前

词典测试模式下，活动模型对金额选择删除。外发文本变成：

```text
例会上郑清越认领海报，曹明川认领签到。印刷费是。有人正在服用降压药。
```

金额没有了，姓名和服药情况还在。没有「约六千元」。随后既有规则因为识别未经验证而暂停，展示为空。删除必要金额不能算任务完成。

## 修复后

同一输入先在本地处理，再受既有的未验证识别暂停拦住，因此在线流程仍不调用云端，展示仍为空。暂停前的外部载荷已经是：

```text
例会上人员癸认领海报，人员壬认领签到。印刷费是。
```

代号随会话变化，上面只是这一次运行的结果。载荷里没有 6400、没有「约六千元」、没有两个人的原名、没有服药情况，也没有映射表。

模型若返回这份载荷，本地整合按展示接收方决定要不要补金额：

- 学生组织负责人向指导老师展示：恢复原名，并补上「印刷费：约六千元」。原文 6400 不出现。
- 同班同学、公开发布、外部模型：不补这句。外部模型和公开发布的边界检查通过的是不含金额的文本。

解析不到金额，或金额不在一千到九千元这一档时，直接暂停，不编造短语，也不把删除当成成功。要求保留结算单原数的请求不走这条补全。

## 失败与回退

| 情况 | 行为 |
| --- | --- |
| 金额无法解析，或不在千元档 | 暂停，不生成外部载荷 |
| 任务要求人员对应，但文本里找不到可代号化的人员 | 暂停，不把姓名原样送出 |
| 外部载荷整理后仍含金额或原名 | 暂停 |
| 识别处于词典测试模式，或 GLiNER 权重不可用 | 沿用原有暂停，不绕过 |
| 展示对象无权接收预算 | 不补金额，不改外发禁令 |
| 模型没有返回内容 | 不把空结果补成任务成功 |
