# 仓库维护与恢复

main保存完整产品与有效资料。功能、修复、研究和整理使用任务分支，PR合并后结束分支。版本使用标签与Release。

远端整理前快照为archive/pre-reorganization-20261121，提交e9e16b8。本机local/archive/repository-backup-20261121/all-refs.bundle包含整理前全部本地与远端跟踪引用，已通过git bundle verify。同目录保留引用清单、未提交项目报告、私有数据压缩包与迁移清单。

恢复Git历史可在新目录执行git clone /absolute/path/all-refs.bundle recovered-shield。查阅旧目录可打开GitHub归档分支。恢复私有资料使用本机备份与迁移清单。

local保存私有原件、环境、输出与备份。app/.env与上传目录沿用忽略规则。GLiNER大权重仍在本机app/models，也可通过SHIELD_GLINER_MODEL_DIR指定位置。

冻结数据、模型产物及评测发布证据按原始字节保留。历史研究脚本提供兼容入口。移动Python虚拟环境后应重新创建，当前Windows工具优先使用SHIELD_PYTHON或本机路径记录。
