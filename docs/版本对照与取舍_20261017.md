# GitHub 与原本地项目的版本对照

对照对象：当前 Git 仓库 `delivery/app` 与原本地目录 `D:/project/隐盾`。原目录含 `.env`、报告、私有输出等，未被覆盖或同步到 Git。本仓库检出位于 `D:/project/LLM-shield`，供后续开发与提交使用。

| 项目 | 实际情况 | 本次处理 |
| --- | --- | --- |
| 默认入口 | Git 仓库启动器固定 mock，原目录有可配置的通用对话入口 | 保留已经验证的名单 mock 入口，新增明确的真实通用对话入口；没有密钥时返回错误 |
| 模型 | Git 只跟踪 `necessity_action.joblib`，`reviewed_ner` 大权重缺失；Campus NER、GLiNER 为关闭的可选代码 | 不把缺失模型当作已可运行，也不把其他模型自动代替 BERT；未发现需要从 Git 删除的冗余大权重 |
| 表格 | Git 版曾只解析首个工作表；部分 WPS 校验标记会导致解析失败；大表逐行送入对话会变慢 | 修复多表解析、标题行/重名列、WPS 标记；相关行检索只取少量行，窄口径计数在本机查完整表 |
| 软件验证 | 空白复核表被 Git 忽略，干净检出的部分测试失败 | 按已入库合成批次与哈希清单重建缺失的空白表，已有人工文件不覆盖 |
| 原目录独有模块 | `processing.py`、`material_processing.py`、`metrics.py`、`runtime.py` 等重构和观测模块未出现在 Git 融合版；Git 新增通知及复核 BERT 路径 | 未整目录覆盖。两边编排契约不同，直接复制会破坏通知链；后续逐模块迁移并配回归用例 |
| 个人资料及模型数据 | 原目录有本机配置、文档与私有输出；仓库缺少这些内容是预期 | 不上传原始表格、密钥、私有报告或本地模型权重 |

本次以**可证实能运行的源码与依赖**为保留标准，没有依据文件名删除可选模型适配器或实验记录。可选适配器处于关闭状态，不在当前启动路径中；真正影响克隆可用性的缺口是 Python 环境、人工复核 NER 权重和被忽略的测试空白表。当前通用对话入口可用规则识别基线，但其真实外发效果还需在配置密钥后用公开合成内容验证。原本地项目的架构重构可能有价值，不能当成冗余一并删除。

本机软件验证：独立 smoke 38/38；pytest 297 passed、1 skipped、90 subtests passed。用户提供的四份 Excel 仅在本机只读解析，未入库；工作表数分别为 1、7、1、6（仅计非空表）。第一份表格的“专业 = 网络空间安全”完整 310 行本机统计为 12，避免以检索片段猜测全表。
