# 隐盾当前架构与限制

更新：2026-10-17。本文描述当前统一启动入口，后续执行顺序以根目录 AI_EXECUTION_PLAN.md 为准。

## 当前实现

FastAPI 提供本机网页及 API；前端为 HTML/CSS/JS。已验证的名单入口强制 mock，监听 127.0.0.1:8789；它需要单独提供 Git 未收录的人工 gold BERT 权重。实体识别由格式规则、词典与人工 gold BERT 组合完成，BERT 使用合法 BIO 序列解码；可选 Campus NER、GLiNER 在此入口关闭。另有 8787 端口的通用真实对话入口，使用规则识别基线和本机密钥配置，尚未完成真实服务联调。

动作模型为 TF-IDF + 逻辑回归，选择 DELETE、LOCAL_AGGREGATE、GENERALIZE、PSEUDONYMIZE、RETAIN 或 PAUSE。权限和安全约束只检查、阻止模型选择，不另选替代动作。转换后在模型输入、用户展示和工具外发三个边界检查实际载荷。效用估计仅供提示，不能覆盖安全否决。

模型路径、哈希及版本以 [ACTIVE_MODELS.json](../delivery/app/models/ACTIVE_MODELS.json) 为准。NER 来源清单保留训练时的历史路径与代码指纹；这类历史字段不是运行依赖，也不能为了路径整洁改写历史来源。

## 两条工作流

通用对话：加载材料与身份权限 → 识别与切分 → 模型选动作 → 约束检查 → 信息转换 → 三边界检查 → 当前本地模拟回复。上传材料保存在本机，会话、代号映射及原值记录的生命周期由聊天模块管理；清除对话与删除上传材料是不同操作。

名单通知：/notice → /api/notice/review 仅在本机识别原名单；另一路 /api/notice/draft 只接收独立公开活动字段，经专用 activity_notice 任务处理。名单、附件 ID、历史及自由任务文本不能作为 draft 参数。未提供的时间、地点、链接不能补造。识别结果不等于人员关系、身份真实性或联系方式有效性的核实。

## 证据与限制

- 原人工复核验证的 BERT 严格 F1 为 99.45%，实际组合链为 98.91%；训练有 152 个展开视图，验证有 116 个视图，其中独立 NER 验证单位 56 个。视图数不能当作独立人数或材料数。
- field_v1 是参与过开发的 87 条材料：组合严格 F1 78.85%，cover F1 89.03%。
- 单条名单的助手调试目标为 20 个直接标识符，全部命中且没有额外实体；该目标不是双人复核 gold，也不覆盖所有间接身份线索。
- 12 项动作软件用例通过 11 项；公共地点被错认作 DORM 会引发暂停。16 条地点探针仅覆盖 10 条，下一步应补充独立对照数据。
- 降低学习率的候选产生中文宿舍漏识别；平均权重候选导致整体分数下降；类别平衡候选没有形成净收益，均未采用。
- 当前未验证真实外部模型的通知质量，身份选择不等同生产认证，完整版本尚未通过干净机器交付验收。

整请求动作实验 policy_context_v2 与应用分段接口不同，不能直接覆盖当前动作模型。保留其证据只用于研究比较。既有开发验证、高度模板化数据与历史测试成绩不能当作新盲测。
