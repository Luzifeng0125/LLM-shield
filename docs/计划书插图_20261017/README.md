## 数据口径提醒

`latency_measurements.json` 与 `latency_samples.csv` 的本地计时只覆盖单进程内的解析、识别、动作、转换与复检，不含上传、磁盘读写、模型加载、界面渲染与外部生成；外部生成是 `deepseek-flash` 非流式往返，三次请求中两次返回有效回答，均值只按两次成功样本计算。这些数值只描述本次设备、材料与配置，不应扩展为普遍性能承诺。
