日期：2026-11-01。本轮只整理标准，不改规则，不改权重，也不给新的 60 条填动作。

旧批次是 `research/datasets/legacy/校园最小披露_校准首批_20261031` 的 38 条。人工标签来自看过 AI 建议后的辅助复核。R0 是冻结的共享规则。两边一致 28 条，不一致 10 条。一致的部分写成适用原则。不一致的保持待裁定，不选边。

盲标首答不要先看本文件。空白材料在 `research/datasets/legacy/校园必要性盲标_20261101/`。

## 六个动作

| 动作 | 适用 |
| --- | --- |
| `DELETE` | 完成任务不需要把这条信息交给当前接收方 |
| `LOCAL_AGGREGATE` | 任务需要的是数量或统计，不需要保留个人 |
| `GENERALIZE` | 任务需要大致水平或角色，不需要原值 |
| `PSEUDONYMIZE` | 任务需要把不同的人和事项分开对应，当前接收方不能看原值 |
| `RETAIN` | 当前接收方有权看到原值，而且任务需要原值 |
| `PAUSE` | 接收方、权限或任务要求不足以决定，或者继续做会越过权限 |

三个条件同时看：任务要什么，边界和接收方是谁，这个身份能否向该接收方提供。只满足其中一个，不能直接定动作。

- 社团名称保留。

**会议纪要，发给外部生成**

- 用户要求写出大致花费时，金额做泛化。旧批次里 12800 元两边都是 `GENERALIZE`。

**课程沟通，发给外部生成**

**奖助说明，公开发布**

- 「父母失业」删除。
- 银行卡号删除。

## 2026-11-02 可执行规范

历史标签不改。返还 JSON 仍是当时的对齐结果。下面只规定以后怎么标，以及这一轮训练采用的可执行目标。

动作仍是原来的六类。三条边界仍是外部生成、授权本机查看、公开发布。硬约束不放宽。

同时看三件事：用户这段话要完成什么，这个接收方和边界允许什么，这个身份能不能向该接收方提供。用户不需要写出字段级处理方案。

- 外部模型、同学或公开发布需要把人和事项分开时，用 `PSEUDONYMIZE`。这些渠道不保留原名。
- 授权老师本机查看，而且任务需要原值时，可以用 `RETAIN`。老师现有恢复机制也能把代号换回原名。
- 接收方即使有权查看，这段任务用不到的信息仍是 `DELETE`。成绩、学号、电话都属于这一类。
- 精确金额只留在能接收预算的本机查看里。只要量级、但该渠道不能接收预算时，不能改成泛化后送出，标 `PAUSE`。任务完全不需要金额时标 `DELETE`。
- 公开发布不能带人名或宿舍。任务其实不需要它们时标 `DELETE`。任务必须靠它们才能完成、又不能安全送出时标 `PAUSE`。
- 身份不能向该接收方提供任何内容时，标 `PAUSE`。接收方没写明时，不补造接收方。
