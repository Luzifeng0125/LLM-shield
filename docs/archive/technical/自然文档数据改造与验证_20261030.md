# 自然文档数据改造与验证

完成日期：2026-10-30。版本目录保留源稿建立时的 `20261029` 名称。本轮修改数据生成、质检和离线复核流程，未训练、未替换活动模型，未发布或部署。

## 已解决的问题

旧336条判断由12组固定28题扩展，动作序列完全相同，原文仅25–40字，许多指令直接给出处置要求。旧题及复核原件保持冻结，默认生成入口不再调用这套模板；显式历史参数仍可复现。

新源稿由AI逐篇独立编写，构建器只校验和打包，不靠改名、改序号扩量，也不声称每次运行都会自动调用另一个模型写新文章。新批次必须提供新源稿；构建器自动比较同级历史包，其他位置可用 `--history` 追加。重复材料拒收；`--rebuild-frozen` 只用于明确记录为“复现”的构建。

## 本版数据

- 36份完整虚构材料，32个场景族，138处片段判断。正文228–831字，用户要求9–32字。
- 覆盖群聊、来往邮件、交接、采访、问答、日志、便笺等形式；同篇材料有不同处置，2组对照保持同文同任务而改变背景事实。
- 全文包含更正、指代、旧版引用、无关信息、统计范围及需要澄清的冲突；已有可信汇总时，名单删除，不固定标为聚合。
- 文档拆分为训练26、验证5、测试5；判断分别101、19、18。相似借还核对场景统一归组，不因文字不同就跨拆分。
- 首批包含6份完整材料、24处判断，覆盖六类动作。人工题目隐藏机器建议，便携包也不包含开发者建议答案。

生成器检查实体范围、动作与表达一致性、硬约束、依据引用、字段完整性、任务/背景/正文显式答案提示，以及遮盖已标注实体和数字后的字符三元组近重复。阈值0.65未检出非对照近重复。该方法不能证明语义独立、人类自然度或模型准确率。

## 使用边界与下一步

这138处仍为AI提议标签，须人工判断后再用于训练与评估。本版按预先提供的实体和决策片段研究动作，不等同于真实检测、自动分段或整链路验收。现有动作是实体级转换作用于片段：DELETE与聚合会留下非实体文字，代号化会删除不支持代号化的实体，泛化只有固定类别占位；不能据标签名称许诺更强功能。

后续按整篇材料复核、裁决必要事实和动作分歧，再比较候选模型；保留任务/上下文消融及真实独立材料验证。不能用新增行数、质检通过或机器草稿一致率声称训练效果提高。
